## 🚀 Featured Projects

### 🧠 [GPT-Style LLM Built from Scratch](https://github.com/Owais-Ml-Dev/GPT-from-Scratch/tree/main)
*Engineered a 163M parameter decoder-only Transformer entirely from first principles.*
* **Core Architecture**: Manually implemented multi-head causal self-attention, learned positional embeddings, and feed-forward networks using **PyTorch**.
* **Training**: Optimized utilizing **AdamW** and trained on a 40k sample instruction dataset, achieving a validation loss of **0.071**.
* **Impact**: Demonstrated mastery of internal LLM mechanics, including tokenization (tiktoken) and generation strategies like Top-K sampling.

### 🎙️ [Speech Emotion Recognition System](https://github.com/Owais-Shaikh-0786/Speech-Emotion-Recognition-with-librosa)
*A deep learning system designed to detect human emotional states from raw audio.*
* **Pipeline**: Utilized **Librosa** for extracting MFCCs, Zero Crossing Rate, and RMS energy features.
* **Modeling**: Compared and deployed **CNN** and **LSTM** architectures to capture both spectral texture and temporal emotional flow.
* **Outcome**: Built a robust classification engine capable of distinguishing nuanced emotions like calm, happy, and angry.

### 👁️ [Real-Time Drowsiness Detection](https://github.com/Owais-Shaikh-0786/Drowsiness-Detection-System)
*A safety-critical computer vision system for driver monitoring.*
* **Tech Stack**: **OpenCV**, **Keras**, **TensorFlow**, **Pygame**.
* **Mechanism**: Tracks eye aspect ratio in real time to detect closure duration. Triggers immediate auditory alerts upon fatigue detection.
* **Optimization**: Optimized for low latency inference to ensure instant feedback in live video feeds.

### 📝 [AI Powered Attendance System](https://github.com/Owais-Shaikh-0786/Attendance_System)
*Automated biometric verification system integrated with cloud storage.*
* **Integration**: Combines **Face Recognition** libraries with **Firebase Realtime Database**.
* **Workflow**: Performs live face encoding, matches against serialized profiles, and logs timestamped attendance automatically without manual intervention.
